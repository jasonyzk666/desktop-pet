操作录制

录一次连招，让它自己重复

Android 免 Root 自用

开发中 · 自用，暂不提供 APK

能 做 什 么

  • 01
    录制手势

    悬浮窗点录制，正常操作手机，按真实间隔完整记下来。

  • 02
    循环回放

    设定次数与间隔，整套动作自动复放，随时中止。

  • 03
    悬浮面板

    游戏内随时呼出，开始 / 停止 / 调速都在手边。

  • 04
    免 Root

    无障碍服务注入手势，不刷机、不连电脑。

技 术 实 现

  • A
    Accessibility Service + dispatchGesture

    用手势注入 API 回放触控。

  • B
    TYPE_ACCESSIBILITY_OVERLAY 悬浮钮

    悬浮控件挂在无障碍窗口层。

  • C
    透明 Activity 承载 Compose

    绕开 ComposeView 挂 WindowManager 的生命周期崩溃。

  • D
    沉浸式录制页

    保证视图坐标与屏幕坐标一致，回放位置才准。

  • E
    黑白简约 UI

    左侧栏 + 右侧内容，窄屏自动切顶部导航。
